# Coreano. — Aprende Coreano de A1 a C2

Sitio web multilingüe (español / inglés / coreano) para aprender coreano desde cero hasta nivel avanzado siguiendo el Marco Común Europeo (CEFR). Diseño bonito, responsivo, con alto contraste, animaciones y **audio de pronunciación**.

## Estructura del proyecto
```
Coreano/
├── index.html          # Página principal
├── css/
│   └── style.css       # Estilos, alto contraste, animaciones y responsive
├── js/
│   ├── data.js         # Contenido: 50 lecciones, quiz y traducciones (ES/EN/KO)
│   └── app.js          # Lógica: idiomas, niveles A1-C2, lecciones, modal, quiz, progreso y audio
└── README.md
```

## Cómo usarlo
1. Abre `index.html` en cualquier navegador moderno (Chrome, Edge, Firefox, Safari).
2. No requiere instalación ni servidor: es un sitio estático.
3. Usa el selector de idiomas (**ES / EN / KO**) arriba a la derecha para traducir la interfaz.
4. Elige un nivel (**A1, A2, B1, B2, C1, C2**) y haz clic en cualquier lección para verla con:
   - **Coreano (Hangul)**
   - **Romanización**
   - **Español**
   - **Inglés**
   - Notas explicativas
5. Pulsa el botón **🔊** para escuchar la pronunciación en coreano (síntesis de voz del navegador).
6. Marca las lecciones como completadas para llevar tu progreso (se guarda en el navegador).
7. Haz el **Quiz** para poner a prueba lo aprendido.

## Características
- ✅ Tres idiomas de interfaz: Español, Inglés, Coreano
- ✅ **6 niveles CEFR:** A1, A2, B1, B2, C1, C2
- ✅ **50 lecciones** organizadas por nivel y categoría (Saludos, Gramática, Partículas, Honoríficos, Negocios, TOPIK, Literatura, etc.)
- ✅ **Audio de pronunciación** en cada lección y en las respuestas del quiz
- ✅ Cada lección con Hangul, romanización, español e inglés
- ✅ Quiz interactivo con retroalimentación y audio de la respuesta correcta
- ✅ Progreso guardado automáticamente (localStorage)
- ✅ Diseño con **alto contraste** para mejor legibilidad
- ✅ Diseño responsive (móvil y escritorio)
- ✅ Animaciones de fondo, botones y alertas (toasts)
- ✅ Cursor personalizado en escritorio
